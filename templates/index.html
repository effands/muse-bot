Penjelasan
Update menarik kode terbaru dari GitHub lalu restart kedua service (panel + operator). Proses berjalan di latar — panel akan mati sebentar saat restart, lalu hidup lagi sendiri. 💾 BACKUP OTOMATIS —
Backup berisi channels_db + tasks_db + config (PIN, token Telegram, kredensial channel) + file state + galeri, diarsipkan terenkripsi (AES-256) di folder backups/ di VPS. Backup tidak pernah dikirim ke Telegram — hanya status. Unduh hanya dari sini (login).
Memuat status backup…
Kunci backup (AES-256): …
Simpan kunci ini di tempat aman (mis. password manager). Tanpa kunci ini, backup terenkripsi TIDAK bisa dibuka bila VPS hilang. Restore memakai kunci yang tersimpan di VPS — kolom kunci di form restore hanya bila kunci VPS hilang.
Penjelasan
Backup harian jalan otomatis tiap hari jam yang kamu atur (default 03:00 WIB, saat sepi) + snapshot otomatis sebelum setiap Update panel + manual dari sini atau Telegram (/backup). Retensi: 3 backup terbaru — yang lebih lama dihapus otomatis. Bila total galeri di atas 2 GB, file video di-skip (gambar + audio + manifest tetap ikut) dan dicatat di daftar. Catatan jujur: backup tersimpan di disk VPS yang sama — melindungi dari data rusak/terhapus & update gagal, BUKAN dari VPS hilang total. Unduh salinannya berkala ke komputermu untuk perlindungan penuh. Restore menimpa config (PIN + token ikut kembali), lalu restart panel + operator — ketik YA di form konfirmasi karena tidak bisa dibatalkan.
⬆️ UPDATE & RESTART
Update panel ke versi terbaru dari GitHub lalu restart? Panel akan mati sebentar. Pastikan tidak ada video sedang dirender.
🔄 RESTART BOT TELEGRAM
Restart bot Telegram (@ziqmusebot)? Bot akan mati sebentar lalu hidup lagi dan mengirim sapaan ke Telegram. Panel tidak ikut restart. Gunakan ini bila perintah Telegram tidak dikenali bot padahal panel sudah versi terbaru.
♻️ RESTORE BACKUP
Restore akan MENIMPA config (PIN panel, token Telegram, kredensial channel), database channel, antrean, dan galeri dengan isi backup ini. File lama disalin dulu ke backups/rollback-*.tar.gz. Panel + operator lalu restart — login lagi setelahnya.
